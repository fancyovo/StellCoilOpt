# Security Policy

Please use the hosting platform's private vulnerability-reporting channel for security issues. Do not open a public issue containing credentials, private infrastructure details or an unpatched exploit.

Reports should identify the affected version or commit, the relevant interface, reproduction conditions and expected impact. Numerical-quality disagreements without a security impact belong in the ordinary issue tracker.

This repository must not contain passwords, tokens, private keys, private contact details, unrelated account identifiers, private hostnames or machine-specific absolute paths.
